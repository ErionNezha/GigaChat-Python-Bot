# GigaChat Python Bot

Chatbot Python me GigaChat AI + ndërfaqe Streamlit — bisedo me AI direkt nga browser-i.

`Python` `Streamlit` `AI`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/GigaChat-Python-Bot/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Vendos kredencialet në .streamlit/secrets.toml, `pip install -r requirements.txt`, `streamlit run main.py`.
